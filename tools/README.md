# tools · 组合盈亏复算

`portfolio_pnl.py` 用来在每次校准后复算两条路径：

1. **一直不动**：按 `03_PORTFOLIO` v5 目标权重，在 `--start` 买入并持有到 `--end`；
2. **按规则减仓**：在指定日期卖出指定产品的指定比例，回款转入 `511360 短融ETF`，再持有到 `--end`。

输出期末市值、盈亏、收益率、最大回撤、逐产品盈亏贡献、期末权重；可直接输出 Markdown 表，粘贴到 `00_STATE §3.1/§3.2`。

## 运行

无需第三方依赖，Python 3.8+：

```bash
# 默认：2026-07-01 起，R1 按 2026-10-22 三只各 1/3
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20

# 只算“一直不动”
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20 --no-rule

# 自定义卖出动作（可重复；frac=1.0 清仓）
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20 \
  --sell 2026-10-22:159516:0.333333 \
  --sell 2026-10-22:516820:0.333333 \
  --sell 2026-10-22:159201:0.333333

# 当前时点“若执行 R1”的应持权重（用于 STATE §3.1）
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20 --r1-date 2026-11-20 --markdown

# 导出
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20 --json
python tools/portfolio_pnl.py --start 2026-07-01 --end 2026-11-20 --csv tools/pnl.csv
```

## 每次校准的更新顺序

1. 把 `--end` 改到最新交易日；
2. 若 R1 仍未执行，`--r1-date` 用最新交易日，看“若现在执行”的应持权重；
3. 若 R1 已执行，把 `--r1-date` 改成实际执行日，复算“按规则”的历史盈亏；
4. 把 `--markdown` 输出的前 7 列粘贴到 `00_STATE §3.1`，再补“当前操作/备注”；
5. 把汇总表粘贴到 `00_STATE §3.2`，并更新结论；
6. 在 `02_LOG` 追加一条校准记录（不改旧条目）。

## 数据与口径

- 行情：腾讯 `web.ifzq.gtimg.cn` 前复权日线；缓存于 `tools/.cache/`，`--refresh` 强制刷新。
- 初始资金默认 1000 万；不计交易费用、冲击成本、分红税。
- 卖出比例按**当前实际持仓**计算；R1 默认 `159516/516820/159201` 各 `1/3`，回款转 `511360`。
- 假设 `--start` 已按目标权重满仓；若实际未满仓，现金部分按 0 收益计，实际亏损会小于输出值。
- 腾讯接口单次约 320 根日线；区间过长请分段。

## 输出说明

- **一直不动**：目标权重买入持有，逐产品盈亏 = 目标金额 × 区间收益率。
- **按规则**：卖出部分按卖出日实现盈亏，剩余部分按期末计算；回款买入的 `511360` 份额单独计算盈亏。
- **最大回撤**：区间内逐日市值相对滚动高点的最大回撤。
- **逐产品盈亏合计** 应等于总盈亏；若差 >0.01 万，脚本会提示（四舍五入/数据源）。
- `--markdown` 输出权重为精确值四舍五入到 2 位；与 STATE 表中手工二次四舍五入的结果可能差 0.01pp。

## 注意

本脚本只做机械复算，不构成投资建议；规则阈值/权重以 `01_PLAYBOOK` 与 `03_PORTFOLIO` 为准。
